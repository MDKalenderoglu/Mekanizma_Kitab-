# Kısaltmalar

Bu listede kitap boyunca kullanılan kısaltmalar toplanmıştır. Her kısaltma metinde ilk geçtiği yerde ayrıca açılır; buradaki liste hızlı başvuru içindir.

| Kısaltma | Açılımı | Türkçe karşılığı |
|---|---|---|
| LoF | loss-of-function | işlev kaybı |
| GoF | gain-of-function | işlev kazanımı |
| HI | haploinsufficiency | yetersiz doz |
| TS | triplosensitivity | fazla doza duyarlılık |
| DN | dominant-negative | dominant-negatif (baskın-olumsuz) etki |
| NMD | nonsense-mediated mRNA decay | nonsense aracılı mRNA yıkımı |
| PTC | premature termination codon | erken sonlanma kodonu |
| UPD | uniparental disomy | uniparental dizomi |
| SV | structural variant | yapısal varyant |
| CNV | copy-number variant | kopya sayısı varyantı |
| SNV | single-nucleotide variant | tek nükleotid varyantı |
| VAF | variant allele fraction | varyant alel fraksiyonu (Türkçe yayınlarda “varyant alel frekansı” da kullanılır) |
| LOH | loss of heterozygosity | heterozigotluk kaybı |
| CN-LOH | copy-neutral loss of heterozygosity | kopya-nötr heterozigotluk kaybı |
| ROH | region of homozygosity | homozigotluk bölgesi |
